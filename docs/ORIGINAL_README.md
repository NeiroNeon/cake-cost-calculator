# Калькулятор кондитера

Одностраничное веб-приложение для расчёта себестоимости кондитерских изделий — бенто-тортов, капкейков, трайфлов и других позиций. Работает целиком в браузере, без сервера и без зависимостей. Все данные хранятся локально.

## Что умеет

- **База продуктов.** Хранит ингредиенты, декор и упаковку с ценой за упаковку и её объёмом. Стоимость за грамм, миллилитр или штуку считается автоматически.
- **Редактирование продуктов.** Каждую позицию базы можно отредактировать — изменить название, единицу измерения, объём упаковки или цену. При сохранении пересчитываются все калькуляторы, где используется этот продукт.
- **Множество единиц измерения.** 26 единиц: г, кг, мг, мл, л, шт, ст. л., ч. л., дес. л., стакан, чашка, щепотка, горсть, капля, упаковка, пачка, банка, коробка, рулон, порция, кусок, ломтик, долька, зубчик, пучок, лист.
- **Несколько калькуляторов.** Каждый со своим названием, иконкой и списком позиций.
- **25 SVG-иконок.** Торты S/M/L, капкейки S/M/L, трайфлы S/M/L, звезда, сердце, цветок, вишня, макарон, круассан, пончик, пирог, мороженое, шоколад, кофе, скалка, венчик, весы, подарок, свеча.
- **Мгновенный пересчёт.** Итог обновляется при каждом изменении, без кнопок «рассчитать».
- **Защита от дураков.** Подтверждение при удалении калькулятора и продукта, предупреждение при дублирующемся названии, блокировка пустых значений и отрицательных количеств, автозакрытие пустого калькулятора.
- **Валюта BYN.** Все суммы отображаются в белорусских рублях.
- **Адаптивность.** Раздельные интерфейсы для ПК и мобильных: поповер на десктопе, нижний лист на телефоне, двухуровневые строки ингредиентов, учёт safe-area и высоты видимой области.

## Как пользоваться

1. **Заполните базу.** Кнопка «База продуктов» в шапке. Для каждой позиции: название, количество в упаковке, единица измерения, цена за упаковку. Например: «Мука пшеничная, 1000 г, 4.85 BYN».
2. **Исправьте ошибки.** Нажмите карандаш рядом с продуктом, измените нужные поля и сохраните — пересчёт произойдёт во всех калькуляторах. Отмена возвращает форму в режим добавления.
3. **Создайте калькулятор.** Кнопка «Новый калькулятор» в сетке. Задайте название, иконку и добавьте позиции.
4. **Добавьте ингредиенты.** В калькуляторе нажмите «Добавить позицию», выберите продукт из списка и введите количество. Единица подставится сама.
5. **Смотрите итог.** Внизу калькулятора отображается общая себестоимость. Она пересчитывается сразу.
6. **Управляйте.** Кнопка с корзиной в шапке калькулятора удаляет его (с подтверждением). В базе продуктов удаление тоже защищено подтверждением.

## Формулы

**Стоимость единицы продукта**

```

цена упаковки ÷ количество в упаковке

```

Пример: 1000 г муки за 4.85 BYN → 4.85 ÷ 1000 = 0.00485 BYN за грамм.

**Стоимость позиции в калькуляторе**

```

стоимость единицы × использованное количество

```

Пример: 120 г × 0.00485 = 0.582 BYN.

**Итоговая себестоимость**

```

сумма стоимостей всех позиций

```

## Структура данных

```json

  "products": [

      "id": "string",
      "name": "Название продукта",
      "unit": "г",
      "packQty": 1000,

  ],
  "calculators": [

Хранится в localStorage под ключом bento_cost_v3. Предыдущий ключ bento_cost_v2 читается для миграции старых данных.

Редактирование продуктов

Продукт редактируется через карандаш в строке базы. В форме появляется заголовок режима и кнопка «Отмена». После сохранения:

· продукт обновляется на месте;
· пересчитываются все калькуляторы, где он используется;
· если база была открыта из окна выбора строки калькулятора, отредактированный продукт автоматически встаёт в эту строку;
· кнопка сохранения меняет плюс на галочку;
· сохранение идёт без перезагрузки и без перерисовки списка целиком.

Удаление и защита

· Удаление калькулятора: подтверждение с названием и количеством позиций.
· Удаление продукта: подтверждение с названием и количеством калькуляторов, где он используется. После удаления позиции исчезают из всех калькуляторов.
· Дубликат имени при добавлении: предупреждение с возможностью всё равно добавить.
· Дубликат имени при редактировании: предупреждение с возможностью сохранить под тем же именем.
· Пустые поля и отрицательные количества блокируют сохранение.
· Пустой калькулятор без названия автоматически удаляется при закрытии.

Технические детали

· Без зависимостей. Один HTML-файл, встроенные CSS и JavaScript.
· Без сервера. Всё работает офлайн после загрузки страницы.
· Без системных диалогов. Все подтверждения и уведомления — собственные модальные окна.
· Учёт мобильной клавиатуры. Используется visualViewport с rAF-троттлингом, переменные --app-height и --app-top синхронизируют высоту оверлеев с видимой областью.
· Без автофокуса в окне выбора продукта. Это исключает конфликт с клавиатурой — пользователь сам решает, когда вводить количество.
· Поля ввода 16px на мобильных. Предотвращает автоматический зум в Safari и Chrome на iOS.
· Режим редактирования не открывает клавиатуру автоматически на мобильных — форма скроллится в видимую область, но фокус остаётся за пользователем.

Поддерживаемые браузеры

· Chrome / Edge: последние 2 версии
· Firefox: последние 2 версии
· Safari: 15+
· Мобильные браузеры на iOS и Android

Ограничения

· Данные хранятся только в текущем браузере. Очистка хранилища или переход в режим инкогнито их удалит.
· Нет синхронизации между устройствами.
· Один продукт используется в нескольких калькуляторах — при удалении продукта его позиции исчезают из всех калькуляторов (с предупреждением).
· При редактировании нельзя изменить id продукта — это внутренний идентификатор, на него ссылаются все калькуляторы.

Лицензия

Свободное использование в личных и коммерческих целях.
