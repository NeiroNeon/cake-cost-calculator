# Формулы и предметная область

## Формулы

- `unitCost = packPrice / packQty`
- `lineCost = unitCost * usedQty`
- `calculatorTotal = sum(lineCost)`

Пример: 1000 г муки стоят 4.85 BYN. Стоимость грамма — 0.00485 BYN; расход 120 г стоит 0.582 BYN.

## Единицы

Исходный интерфейс поддерживает: г, кг, мг, мл, л, шт, ст. л., ч. л., дес. л., стакан, чашка, щепотка, горсть, капля, упаковка, пачка, банка, коробка, рулон, порция, кусок, ломтик, долька, зубчик, пучок, лист.

## Важное ограничение

Калькулятор считает стоимость расхода по цене единицы продукта. Он не конвертирует физически граммы в миллилитры, ложки в граммы или объём в массу: для этого нужна плотность/специфический коэффициент ингредиента. Суммирование строк означает сложение денежных затрат, а не смешение физических величин.

## Данные

Продукт: `id`, `name`, `unit`, `packQty`, `packPrice`.
Калькулятор: `id`, `name`, `icon`, `items`.
Строка: `productId`, `qty`.
