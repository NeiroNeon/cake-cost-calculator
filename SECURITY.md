# Безопасность

Не публикуйте в Issues резервные копии с личными данными или содержимым пользовательской базы. Для сообщений о потенциальной уязвимости используйте приватный механизм Security Advisories GitHub в репозитории.

Приложение не имеет backend и не отправляет пользовательские данные на сервер. Риски включают XSS при будущих изменениях интерфейса, подмену статических файлов при компрометации хостинга и потерю localStorage при очистке браузера. Не импортируйте неизвестные JSON-файлы. Импорт проверяет структуру, числа, уникальность ID и связи позиций с продуктами.
