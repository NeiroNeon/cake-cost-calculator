# Changelog

## [1.1.1] — 2026-11-05

- Исправлен offline fallback service worker для отдельного маршрута `/app/`.
- Ошибка записи в localStorage теперь отображается пользователю с подсказкой по резервному экспорту.
- Улучшены возврат фокуса, базовый focus loop, доступные имена полей и live announcement суммы.
- Снижена стоимость декоративных эффектов на мобильных экранах; минимальная зона нажатия основных controls — 44 px.
- Добавлен Playwright Chromium smoke suite на 8 viewport и запуск в CI с артефактами отчёта.
- Уточнена документация аудита: эмуляция viewport не выдаётся за физические тесты устройств.

## [1.1.0] — 2026-11-05

- Исправлена адаптивность лендинга на узких экранах и доступность мобильной навигации.
- Ужесточена проверка ID в JSON-резервных копиях и экранирование HTML-атрибутов.
- Обновлена изоляция кеша service worker.
- CI переведён на полный `npm run check`; добавлен отчёт аудита интерфейса и решение по motion/UI-библиотекам.


## 1.0.0 — Production-ready static release

- Сохранён исходный калькулятор и обратная совместимость `bento_cost_v3` / `bento_cost_v2`.
- Добавлены резервный экспорт/импорт JSON и проверка структуры.
- Вынесены функции расчёта и добавлены unit-тесты.
- Создан адаптивный motion-лендинг с живым демо.
- Добавлены PWA manifest, service worker, CI и GitHub Pages deployment.
- Добавлена документация и community-файлы.
