# Pastry Studio — MVP технологических карт

Этот патч добавляет отдельный модуль базы рецептов в существующий Cake Cost Calculator.

## Возможности MVP

- Каталог рецептов с поиском и фильтром по категории.
- Технологическая карта: выход, ингредиенты, этапы, температура, время, хранение и примечания.
- Комбинированные ингредиенты: выбор продукта из общей закупочной базы или свободная текстовая позиция без цены.
- Расчёт стоимости только по привязанным позициям. Непривязанные ингредиенты явно помечаются, а итог обозначается как неполный.
- Проверка совпадения единиц измерения. Автоматической конвертации граммов в миллилитры и других сомнительных преобразований нет.
- Масштабирование количеств по целевому выходу.
- Отдельный JSON-экспорт и импорт базы рецептов.

## Хранение

Рецепты хранятся отдельно в `localStorage` под ключом `bento_recipes_v1`. Закупочные продукты читаются из `bento_cost_v3`. Модуль не изменяет и не мигрирует старые калькуляторы, поэтому исходные данные калькулятора остаются нетронутыми.

Если закупочный продукт удалён или его ID больше не найден, связанная строка перестаёт участвовать в расчёте и карта показывает неполную себестоимость. Это безопаснее, чем подставлять другую позицию по совпадению названия.

## Ограничения первой версии

- Составные рецепты (рецепт внутри рецепта) пока не включены в UI; это следующий этап после проверки базового сценария.
- Единицы измерения должны совпадать буквально. Для пересчёта кг↔г и л↔мл потребуется отдельная безопасная таблица конвертаций с исключениями для штук и объёмных мер.
- Фотографии, аллергены, выход после выпечки и потери массы, история изменения закупочных цен и печатная форма технологической карты запланированы на следующие итерации.
- Данные local-first и привязаны к браузеру/устройству. Используйте JSON-экспорт для переноса.

## Проверка

```bash
node --check app/src/recipes.js
node --check app/src/recipes-domain.js
node --test tests/recipes.test.js
npm run check
```

Модуль открывается через кнопку «Технологические карты» в шапке калькулятора либо напрямую по `/app/recipes.html`.
