# Участие в проекте

1. Создайте fork и отдельную ветку для изменения.
2. Сохраните обратную совместимость `bento_cost_v3`, если изменение затрагивает данные.
3. Не добавляйте серверную синхронизацию, аккаунты, аналитику или обязательные внешние сервисы без отдельного обсуждения.
4. Для расчётной логики добавьте unit-тесты.
5. Проверьте `npm test` и ручной запуск через HTTP.
6. Откройте Pull Request с описанием проблемы, решения и тестирования.

Для интерфейса учитывайте мобильную клавиатуру, safe-area, доступность, контрастность и `prefers-reduced-motion`.
