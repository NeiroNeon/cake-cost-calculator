# Product quality rules (anti-slop)

1. Функция важнее декоративного эффекта: motion не должен мешать вводу, чтению итогов и доступности.
2. Не подключать несколько анимационных движков для одинаковых переходов.
3. Математика имеет один источник истины — `app/src/domain.js`, покрытый unit-тестами.
4. Не выдумывать физическую конверсию g↔ml или ложек без ингредиентных коэффициентов/плотности.
5. Ошибки localStorage должны быть видимы; пользователю нужен совет экспортировать JSON.
6. localStorage — не вечная резервная копия; честно предупреждать о риске потери данных.
7. Не заявлять PASS для браузера/устройства, если тест не запускался. Разделять unit, viewport emulation, физические устройства, Lighthouse и production deployment.
8. Mobile UX: доступные touch targets, клавиатура, возврат фокуса, safe areas, отсутствие горизонтального overflow.
9. Уважать `prefers-reduced-motion`; функциональность не зависит от анимации.
10. Каждая зависимость требует измеримой пользы, проверки лицензии, offline-поведения и обслуживания.
